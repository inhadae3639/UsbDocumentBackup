DocumentBackup 개인정보처리방침

최종 수정일: 2026-09-09

DocumentBackup(이하 "이 앱")은 Windows에서 동작하는 개인용 백업 프로그램입니다. 사용자가 PowerPoint로 연 발표 자료를 사용자 본인의 PC에 보관하고, 사용자가 직접 연결한 사용자 본인의 Google Drive 계정에 업로드합니다.

이 앱에는 서버가 없습니다. 개발자는 사용자의 파일이나 계정 정보를 수집하거나 전송받지 않으며, 어떠한 데이터도 볼 수 없습니다.

1. 다루는 정보

구분내용보관 위치
발표 문서 사용자가 이 PC에서 연 .ppt / .pptx 파일의 사본 사용자 PC, 그리고 사용자가 연결한 Google Drive
파일 메타데이터 파일 이름, 원본 경로, 크기, 수정 시각, SHA-256 해시, 저장장치 표시명 사용자 PC의 로컬 데이터베이스
Google 인증 정보 OAuth 갱신 토큰 사용자 PC. Windows DPAPI로 현재 사용자 계정 전용 암호화
Google 계정 이메일 연결된 계정을 표시하고, 재연결 시 다른 계정으로 잘못 업로드되는 것을 막기 위한 용도 사용자 PC의 설정 파일

2. 요청하는 Google 권한

이 앱은 https://www.googleapis.com/auth/drive.file 범위만 요청합니다. 이 범위는 이 앱이 직접 만든 파일에만 접근할 수 있습니다. 사용자의 Drive에 이미 있던 다른 파일은 이 앱이 읽거나 수정하거나 삭제할 수 없습니다.

Drive 전체 접근 권한은 요청하지 않습니다.

3. 정보를 보내는 곳

업로드 대상은 사용자가 로그인하여 직접 연결한 사용자 본인의 Google Drive뿐입니다. 그 외 어떤 서버로도 데이터를 전송하지 않습니다. 분석 도구, 광고, 오류 수집 서비스, 제3자 제공은 일절 없습니다.

4. 보관 기간

  • 연 적이 없는 자료의 로컬 사본: 7일 후 자동 삭제
  • 연 발표 자료의 로컬 사본: Google Drive 업로드가 확인된 뒤 7일이 지나면 삭제
  • Google Drive에 올라간 파일: 이 앱은 원격 파일을 자동으로 삭제하지 않습니다. 사용자가 직접 관리합니다.

5. 사용자의 통제 수단

  • 연결 해제: 앱 설정에서 언제든 Google 연결을 끊을 수 있으며, 저장된 토큰은 삭제됩니다.
  • 권한 철회: Google 계정 권한 관리에서 이 앱의 접근을 철회할 수 있습니다.
  • 로컬 데이터 삭제: %LOCALAPPDATA%\DocumentBackup 폴더를 삭제하면 보관본·데이터베이스·토큰이 모두 사라집니다.
  • Drive 파일 삭제: Google Drive에서 직접 삭제하면 됩니다.

English summary

DocumentBackup is a personal Windows backup utility. It copies PowerPoint presentations the user opened on their own PC and uploads them to the user's own Google Drive account, which the user connects themselves.

There is no server and no developer-side collection. The developer never receives, stores, or can access any user file or credential.

The application requests only the drive.file scope, which grants access solely to files this application itself creates. It cannot read, modify, or delete any pre-existing file in the user's Drive. Full Drive access is never requested.

OAuth refresh tokens are stored locally and encrypted with Windows DPAPI, scoped to the current Windows user account. No analytics, advertising, crash reporting, or third-party sharing of any kind is performed. Data is transmitted only to the user's own Google Drive.

Users may disconnect the account in the application at any time, revoke access at Google Account permissions, and delete all local data by removing the %LOCALAPPDATA%\DocumentBackup folder.
