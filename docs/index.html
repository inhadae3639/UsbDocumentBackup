발표 자료를 놓치지 않는 Windows 백업 프로그램

Windows 로그인 후 트레이에 상주하면서, 이 PC에서 연 PowerPoint 발표 자료를 저장 위치와 관계없이 찾아 PC에 보관하고 Google Drive에 업로드합니다. USB에 있지만 한 번도 열지 않은 자료는 임시로만 보관합니다.

보관 방식

등급대상Drive로컬 보관
영구 이 PC에서 연 .ppt / .pptx 업로드 업로드가 확인된 뒤 7일
임시 USB에 있으나 연 적 없는 .ppt / .pptx 올리지 않음 7일

동작 원칙

  • 원본은 읽기 전용으로만 접근합니다. 이름 변경·이동·삭제·수정을 하지 않습니다.
  • 모든 사본은 SHA-256으로 검증한 뒤에만 완료로 기록합니다.
  • 발표를 방해하지 않도록 콘솔·진행창·알림 팝업을 띄우지 않고 포커스를 가져가지 않습니다.
  • Google 권한은 drive.file만 요청합니다. 이 앱이 만든 파일 외에는 접근하지 못합니다.
  • 토큰 만료 시 브라우저를 자동으로 열지 않습니다. 사용자가 연결 버튼을 누를 때만 인증합니다.
